# sound/

- `sfx/` — the bundled sound-effect library (103 CC0 sounds in 12 categories + `manifest.json`), from
  Barty-Bart/motion-graphics. All CC0 (Freesound, Kenney); see `LICENSES.md`.
- `MUSIC.md` — suggested free tracks by feel (Mixkit, downloaded at runtime, never committed) and what their licence allows.
- The pass itself is `render/sound.py`; the guide is `docs/SOUND.md`.
