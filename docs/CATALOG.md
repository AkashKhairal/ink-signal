# Catalog

Generated by `node tools/catalog.mjs`. Two engines, one plan format:

- **IS Spec comps** (canvas renderer, rebuilt natively in After Effects): titles, A-roll overlays, captions, transitions, 3D.
- **Signal Motion scenes** (browser engine: springs, camera, cursor, UI kit, charts): explainers, B-roll, infographics, cards, kinetic titles, object transitions. Delivered to editors as rendered ProRes (4444 with alpha for overlays).

Any name below works in `node render/cli.mjs render <name> --format reel|yt|square --params '{…}' --out file` and as `"comp"` in an edit plan.

#### `tr-flood` — Line → flood
A thin accent line draws across, wobbles, then floods the frame (cover at CUT) and slides away to reveal the next shot.

- Formats: yt, reel, square · default theme: night · transparent · default length 1.3 s
- Params: `format`="yt" · `color`="accent" · `label`="" · `cover`=0.75

#### `tr-dot` — Dot → iris
A dot grows from a point into a full-frame disc (cover at CUT), then irises out to reveal the next shot.

- Formats: yt, reel, square · default theme: night · transparent · default length 1.1 s
- Params: `format`="yt" · `color`="accent" · `x`=null · `y`=null · `cover`=0.5

#### `tr-bars` — Bars wipe
Staggered ink bars (one in the accent) close over the frame, hold 2 frames for the cut, then open the other way.

- Formats: yt, reel, square · default theme: night · transparent · default length 1.3 s
- Params: `format`="yt" · `color`="ink" · `alt`="accent" · `n`=6 · `cover`=0.6

#### `tr-zoom` — Word zooms through
A word pops in and flies at the camera until its letters swallow the frame; the fill colour takes over at CUT, then wipes away.

- Formats: yt, reel, square · default theme: night · transparent · default length 1.5 s
- Params: `format`="yt" · `text`="Next" · `color`="accent" · `fill`="accent" · `cover`=0.95
