# DaVinci Resolve

Make the package: `node render/nle.mjs plan.json --out pkg`

## No scripting

File › Import › Timeline… → `pkg/timeline.xml` (FCP7 XML). Resolve relinks the media from the paths in the file.

## With a Resolve MCP that runs Python

```python
import importlib.util
spec = importlib.util.spec_from_file_location("ink_signal_resolve", "/abs/ink-signal/integrations/davinci-resolve/ink_signal_resolve.py")
isr = importlib.util.module_from_spec(spec); spec.loader.exec_module(isr)
# isr.use_resolve(resolve)                # only if the MCP hands you a `resolve` object
isr.assemble("/abs/pkg")                  # V1 picture, V2 overlays, V3 transitions, A1 clip audio, A2 music, markers
isr.add_title("Setup", at_frame=90)       # (beta) native Fusion Text+ in Ink & Signal type, colour and 'land' easing
```
A plain `exec(open(".../ink_signal_resolve.py").read())` also works; then call `assemble(...)` directly.

## From a terminal

Resolve running, Preferences › System › General › External scripting using = Local:
```bash
python3 integrations/davinci-resolve/ink_signal_resolve.py /abs/pkg
```

## Notes

- Uses `MediaPool.AppendToTimeline` with `recordFrame` and `trackIndex` (Resolve 18+).
- Timeline frame rate/resolution come from the manifest; Resolve only lets the project frame rate change before the
  first timeline exists, so the script also sets per-timeline custom settings.
- `ink_signal_tokens.py` is generated by `tools/build.py` from the tokens file.
- Not tested in every Resolve version here; `assemble()` prints what it placed and lists any missing files.
