Ink & Signal

A motion design system you can render.

Reels, YouTube edits and SaaS explainers that look like they came from one studio. Every frame is code: previewed live in your browser, rendered to MP4 or ProRes, and rebuilt natively in After Effects, Premiere Pro and DaVinci Resolve. Built for Claude.

Explainers

A whole product video from one params file. Write the words, keep your accent colour, and the template does the timing: beats, camera moves, cursor clicks and sound cues.

    Install

    You need Node 18+, ffmpeg and Python 3 with numpy and Pillow. Playwright drives a headless Chromium that renders every frame.

    git clone https://github.com/AkashKhairal/ink-signal.git && cd ink-signal
npm install && npx playwright install chromium

node render/cli.mjs list        # every template and what it does
node render/serve.mjs           # this website + live stages at http://127.0.0.1:5178/

    Optional: pip install faster-whisper for word timings, and transformers + torch for SAM 2 cut-outs (title behind you).

    Look before you render

    A contact sheet renders a handful of moments in seconds. Check it for anything clipped, overlapping, unreadable or off-brand, then render.

    node render/cli.mjs sheet ig-bars --format reel --auto 9 --out check.png        # 9 evenly spaced frames
node render/cli.mjs sheet mb-terminal --times 0.5,1.9,2.8,5.4 --out words.png   # stills on the key words
node render/cli.mjs still t-slam --frame 60 --out slam.png

    always look first

    Render

    Any template, any format. Params override the template's defaults (each one's are in the live player and in CATALOG.md).

    node render/cli.mjs render t-slam --format reel --params '{"text":"Orbit","human":"made for creators"}' --out slam.mp4
node render/cli.mjs render ig-counter --format yt --params-file stat.json --blur 4 --out stat.mp4
node render/cli.mjs render x-hype --params '{"product":"Orbit","accent":"#2B6BF2"}' --blur 4 --out promo.mp4
node render/cli.mjs render tr-flood --params '{"transparent":true}' --out flood.mov     # ProRes 4444 + alpha
    OptionWhat it does
    --formatreel 1080×1920 · yt 1920×1080 · square 1080×1080 · portrait 1080×1350 (edit plans)
    --params · --params-fileJSON merged over the defaults. Motion scenes also take accent, theme, transparent, width, height, fps.
    --blur NReal motion blur: N subframes per frame. 1 for drafts, 4 for finals (slower: one screenshot per subframe).
    --out.mp4 H.264 · .mov ProRes (4444 with alpha for transparent templates) · .webm · folder/ PNG sequence
    --from · --toRender a frame range only.
    --no-grainSkip film grain (smaller files, GIFs).

    Every render also writes .markers.json (cuts and beats) and .cues.json (sound cues) next to the file. Motion scenes render at any size — 720p, 4K, GIF-sized — and stay the same picture.

    Edit plans

    A whole Reel or YouTube video in one JSON file: your clips, any templates, overlays on clips, transitions on cuts, music. Cuts can snap to the downbeats of your track.

    {
  "name": "launch-reel", "format": "reel", "fps": 30, "accent": "#F2362B",
  "audio": { "music": "music/track.mp3", "musicGainDb": -9, "lufs": -14 },
  "snap": "downbeat",
  "timeline": [
    { "type": "comp", "comp": "t-countdown", "params": { "word": "Ship" } },
    { "type": "transition", "comp": "tr-bars" },
    { "type": "clip", "src": "clips/talk.mp4", "in": 4.2, "out": 9.8, "look": "aroll",
      "overlays": [ { "comp": "ov-captions", "at": 0, "params": { "words": [ { "text": "First", "start": 0.1, "end": 0.45 } ] } } ] },
    { "type": "comp", "comp": "ig-counter", "params": { "value": 12400, "label": "Signups in week one" } },
    { "type": "transition", "comp": "tr-flood" },
    { "type": "comp", "comp": "endcard", "duration": 3 }
  ]
}
    python3 render/beats.py track.mp3 --out beats.json            # tempo, beats, downbeats, the drop
python3 tools/words.py talk.srt --from 4.2 --to 9.8 --out words.json
node render/cli.mjs sheet plan.json --frames 0,30,60,90,120 --out review.png
node render/build-reel.mjs plan.json --out reel.mp4 --blur 3 --beats   # picture + audio, −14 LUFS
    ItemFields
    compAny template name plus params. IS Spec comps take a duration; motion scenes set their own length (end / dur params change it).
    clipsrc, in, out (source seconds), look: aroll (clean) or behindTitles (blurred, darker, pushed in), overlays.
    overlays{ comp, at, params } over a clip — ov-* or any motion scene with "transparent": true.
    transitionSits on the cut between its neighbours: tr-flash, tr-torn, tr-ticker, tr-paper-roll, tr-flood, tr-dot, tr-bars, tr-zoom.

    SaaS explainers

    Write the beat sheet first: time, what is on screen in exact words, what carries the eye across each change. Then fill the template's params with the product's real wording. Never invent customer counts, ratings or quotes; example UI content is fine.

    x-hype12–20 s promo

    Spark → brand slam → kinetic triplet → 3D signature → product moment → end card, on 8 bars. Set bpm and offset from beats.py.

    x-demo30–90 s demo

    Short lines the camera pushes into, then the UI rebuilt up close: prompt, steps, table, chat, chart. 45 s fits 2–3 features.

    x-journey10–16 s loop

    The workflow as stations a ball rolls through in one take: toggle, slider, notification cards, keyboard, launch, reveal, loop.

    node render/cli.mjs sheet x-demo --params-file demo.json --auto 12 --out check.png
node render/cli.mjs render x-demo --params-file demo.json --blur 1 --out draft.mp4       # send for review
node render/cli.mjs render x-demo --params-file demo.json --blur 4 --out demo_silent.mp4 # final + demo_silent.cues.json

    Motion B-roll for talking heads

    Each clip is one shape that never cuts: it morphs between states while a cursor clicks and drags, and every change lands on a spoken word. Cut it in full-frame, or as a transparent panel beside the speaker.

    python3 tools/inspect_video.py talk.mp4 work/     # layout: full / pip / black sections + contact sheet
python3 tools/words.py talk.srt --out work/words.json
node render/broll.mjs broll.plan.json --draft     # fast review renders
node render/broll.mjs broll.plan.json             # final: clips, TIMING.md, preview.mp4, review.html, cues.json
    { "title": "Opus vs Max", "video": "talk.mp4",
  "clips": [
    { "id": "01", "scene": "mb-launch", "in": 0.30, "out": 6.75, "kind": "full",
      "params": { "name": "Opus 5.5", "at": { "badge": 0.63, "card": 2.17, "picker": 4.06, "clicks": [4.5, 4.85, 5.3] } } },
    { "id": "02", "scene": "mb-terminal", "in": 6.75, "out": 22.5, "kind": "panel", "center": [1300, 540] }
  ],
  "notes": ["The typed prompt is illustrative."] }

    at times are clip-local (word time − clip in). center is in the video's pixels. Clips render at the video's resolution and frame rate.

    Sound pass

    Renders write a cue list. The pass places one real CC0 sound on each cue, checks the music's beat grid against the kicks, moves the music so hard cuts land on beats, ducks it under voice, and measures the exported MP4.

    node render/cues.mjs plan.json --out cues.json            # edit plans; single renders write <out>.cues.json
python3 render/sound.py --video reel.mp4 --cues cues.json --music track.mp3 \
  --music-source "Track, Artist, link" --music-license "…" --align --voice auto --out sound/
# sound/after.mp4 · SOUND.md · beatgrid.png · checks/ · report.html (swap any sound) · CREDITS.txt

    Targets: −14 LUFS integrated, true peak below −1.5 dBTP, music −12 dB under effects and −10 dB under voice. Nobody can judge a mix by reading numbers: SOUND.md lists five timestamps to check with headphones.

    Write your own scene

    A scene builds its DOM once; update(t) sets everything for time t. No timers, no CSS transitions, no Math.random — any frame renders on its own, which is what makes motion blur, parallel renders and seamless loops work.

    import { defineScene } from '../scene.js';
import { morph } from '../morph.js';
import { segmented } from '../ui.js';

export const mbExample = defineScene({
  name: 'mb-example', kind: 'broll', title: 'Example', formats: ['yt', 'reel'],
  defaults: { at: { card: 1.2, click: 2.4 }, end: 4 },
  duration: (p) => p.end,
  build(ctx) {
    const { S, p } = ctx;
    const m = ctx.add(morph(S, { states: { pill: { w: 420, h: 110, r: 55, bg: 'control', cam: 1.8 },
                                          card: { w: 900, h: 320, r: 40, bg: 'surface', cam: 1.4 } },
                                 start: 'pill', seq: [[p.at.card, 'card']] }));
    ctx.add(segmented(S, m.layer({ tin: p.at.card }), { items: ['Low', 'High'], index: [[p.at.click, 1]] }));
    ctx.cursor({ keys: [[0, 500, 300], [p.at.click - 0.25, 115, 0], [p.end, 200, 120]], clicks: [p.at.click] });
    ctx.cue(p.at.card, 'movement', 'morph');
  },
});
